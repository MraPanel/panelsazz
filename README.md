# ربات فروش پنل پاسارگاد

## راه‌اندازی
```bash
pip install -r requirements.txt
cp .env.example .env      # BOT_TOKEN و ADMIN_IDS را پر کنید
python bot.py
```
بعد در ربات `/admin` را بزنید و از «⚙️ تنظیمات» این موارد را وارد کنید:
آدرس پنل، نام‌کاربری و رمز ادمین اصلی (یا API Key)، شماره کارت و نام صاحب کارت.

## امکانات
- خرید پنل: ساخت ادمین در پاسارگاد با محصولات تعریف‌شده توسط شما
- محصول «ثابت» (مثلاً یک‌ماهه/نامحدود در زمان) و محصول «پرداخت به ازای مصرف» (قیمت هر گیگ، کسر خودکار از کیف پول هر ۵ دقیقه؛ با اتمام موجودی پنل غیرفعال و پس از شارژ خودکار فعال می‌شود)
- سرویس‌ها: مشاهده وضعیت/مصرف، تغییر رمز (دلخواه یا تصادفی)، تمدید
- حساب کاربری: موجودی، مجموع شارژها، مجموع پرداخت‌ها، تعداد پنل‌ها
- شارژ کیف پول: کارت‌به‌کارت با ارسال رسید و تأیید/رد توسط مدیر
- مدیریت قیمت: قیمت محصولات به دلار، نرخ دلار خودکار از اینترنت (کش ۶۰ ثانیه) یا دستی، درصد سود روی نرخ
- ویرایش همه متن‌ها و نام دکمه‌ها از پنل مدیریت؛ همه دکمه‌ها شیشه‌ای (Inline)
- مدیریت کاربران (افزایش/کاهش موجودی، مسدودسازی)، آمار، پیام همگانی

## نکات مهم
- **API پاسارگاد:** مسیرهای ادمین (`/api/admin`, `/api/admins`, `/api/admin/{username}`) در کلاس `Panel` داخل `bot.py` جمع شده‌اند. چون ساختار دقیق آن‌ها بین نسخه‌ها ممکن است فرق کند، یک‌بار با پنل خودتان تست کنید و در صورت نیاز فقط همان کلاس را اصلاح کنید. فیلدهای اضافه برای ساخت ادمین از «JSON اضافه» در تنظیمات قابل افزودن است.
- **انقضا و سقف حجم** را خود ربات اعمال می‌کند (غیرفعال‌سازی ادمین هنگام انقضا یا اتمام حجم).
- **نرخ دلار:** منبع پیش‌فرض tgju است؛ آدرس و مسیر JSON از تنظیمات قابل تغییر است. اگر دریافت نرخ شکست بخورد، آخرین نرخ موفق استفاده می‌شود.
- پایگاه داده SQLite در `bot.db` است؛ از آن بکاپ بگیرید.
